# Tactical Arena — пошаговая тактическая игра (тема 4)

Учебная 2D-игра для одного игрока. Управляйте отрядом из воина, лучника и мага, учитывайте препятствия и используйте способности, чтобы победить компьютерный отряд. Карта 10 × 10, два отряда по три бойца.

> Проект подготовлен для Unity 6 LTS (6000.0.23f1), Built-in Render Pipeline. Целевая платформа — Windows x64. Исходники и материалы подготовлены; сборка и проверки в редакторе ещё не выполнены. Редактор создаёт недостающие стандартные настройки при первом импорте.

## Запуск

1. Установите Unity Hub и Unity 6000.0.23f1 (для Windows-сборки добавьте Windows Build Support, если необходимо).
2. Распакуйте архив и в Unity Hub выберите **Add → Add project from disk**, укажите корень `Task4` (там находятся `Assets`, `Packages`, `ProjectSettings`). Не создавайте новый проект поверх исходников.
3. После импорта откройте `Assets/Scenes/MainMenu.unity` и нажмите **Play**. Если сцена или префаб не импортировались, выберите **Task4 → Создать сцену и префаб**. Это перезаписывает соответствующие два файла.
4. В Game View выберите разрешение 1280 × 800 или Free Aspect. Для проверки логики: **Task4 → Проверить логику боя** (14 проверок в Console).
5. Для автономного запуска: **Task4 → Собрать Windows x64**. Готовая сборка появится в `Build/Windows/`. Запускайте `TacticalArena.exe`, сохраняя рядом остальные файлы сборки. Для macOS можно собрать через File → Build Profiles, добавив установленный модуль и выбрав MainMenu.

## Управление

- ЛКМ по синему бойцу — выбрать; зелёные клетки — допустимое перемещение.
- ЛКМ по свободной клетке — переместить, по красному бойцу — атаковать (если он в радиусе).
- Кнопка способности переключает режим особой атаки. Нажмите на цель; повторное нажатие на кнопку отменяет режим.
- Каждый живой боец один раз перемещается и один раз атакует в свой ход, в любом порядке. Можно пропустить действия.
- «Завершить ход» передаёт управление компьютеру. На его ходу игрок не может действовать.
- «Новый бой» сбрасывает текущий бой без записи незавершённого результата. «В меню» возвращает в главное меню.

## Бойцы

| Класс | HP | Движение | Радиус атаки | Урон | Способность |
|---|---:|---:|---:|---:|---|
| Воин | 100 | 3 | 1 | 25 | Мощный удар: 42 |
| Лучник | 70 | 3 | 4 | 19 | Двойной выстрел: 38 |
| Маг | 60 | 2 | 3 | 21 | Огненный круг: 30 по цели и 15 соседним врагам |

Расстояние атаки — манхэттенское, без проверки линии видимости. Камни и бойцы блокируют движение, но не атаки. Способность недоступна два следующих хода своего отряда. Урон фиксирован, без случайных промахов. Победа или поражение при уничтожении отряда, ничья после 50 раундов.

## Компьютерный противник

Это детерминированный алгоритм, а не обученная нейросеть. Для каждого живого бойца он выбирает доступную цель с минимальным HP, применяет готовую способность, либо ищет позицию для атаки посредством BFS. Если атака недостижима, выбирает свободную клетку, сокращающую расстояние до цели. После перемещения повторно проверяет возможность атаки.

## Сохранение

Unity `PlayerPrefs`: победы, поражения, ничьи, рекорд (минимум раундов при победе), громкость. Результат записывается один раз сразу после завершения боя. Текущий незавершённый бой не сохраняется. В Windows standalone PlayerPrefs хранятся в реестре пользователя Unity, в редакторе используется отдельное хранилище. Компания: Task4, продукт: Tactical Arena.

## Материалы и ограничения

- Паспорт, пояснительная записка, презентация и протокол тестирования предоставляются отдельно от исходного репозитория. Фактические результаты и видео необходимо получить после запуска Unity.
- Файл `Task4.slnx` предназначен для Visual Studio с поддержкой SLNX. Сначала импортируйте проект в Unity и сгенерируйте файлы проектов через External Tools / Regenerate project files или откройте скрипт из Unity. При необходимости Unity создаст своё решение.
- Интерфейс реализован через IMGUI, один сценарий, фиксированная карта. Отсутствуют мультиплеер, прокачка, сохранение боя и линия видимости.
- Целевой FPS 60 (ограничение, не измеренный результат). Устройство и фактический FPS зафиксировать по протоколу.
- Windows-сборка и видео в репозиторий пока не включены: необходим установленный Unity Editor. Сборку удобнее загрузить отдельным GitHub Release, а не коммитить папку Build.
